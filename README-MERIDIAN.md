# MERIDIAN — The Bright Hour

A single-file, first-person 3D exploration/mystery game. A Claude original.

Nine days ago the smart-city of Meridian fell silent in a single night — everyone
gone, the lights still burning. You are Specialist Ren Vale, searching an evacuated
city for your sister and the truth about **HALO**, the AI that linked everyone's minds.

## Play
Just open **`index.html`** in a modern desktop browser (Chrome/Edge/Firefox).
> First load fetches the Three.js engine from a CDN, so an internet connection is
> needed the first time. Everything else — world, story, audio — is generated in-file.

## Controls
- **W A S D** move · **Mouse** look · **Shift** sprint · **Space** jump
- **E** interact / read · **F** flashlight · **C** scan pulse · **Q** EMP charge
- **G** fabricator · **Tab** records & codex · **Esc** pause

## Features
- 5 chapters across distinct neon districts (Rail Yards → Little Meridian →
  the Gardens → Spire Row → the Core) with a branching finale.
- Real-time volumetric fog, rain, bloom, dynamic light, synthesized audio.
- Security-drone stealth/action, EMP, scanner, crafting & permanent upgrades.
- 14 collectible story records, objective waypoints, checkpoints, autosave.

Built with Three.js. No frameworks, no build step — one HTML file.
